# 이미지 생성 프롬프트 모음

마음 SIGNAL LAB에 필요한 일러스트 에셋 생성용 프롬프트입니다.
각 블록을 **그대로 복사해서** 이미지 생성 AI에 붙여넣으면 됩니다.
(ChatGPT · Gemini · Nano Banana 등 어디서든 동작하도록 한국어로 작성했습니다.)

생성한 파일은 **아래에 적힌 경로·파일명 그대로** 주시면 됩니다.
파일명이 다르면 코드에서 잡히지 않습니다. (확장자는 `.webp`/`.png` 둘 다 동작)
목록과 현재 진행 상황은 [`README.md`](./README.md) 참고.

> 생성 AI가 만드는 PNG 원본은 장당 2MB가 넘습니다. 그대로 커밋하면
> 수업 환경에서 너무 무거우니, PNG로 주시면 제가 WebP로 변환해 넣겠습니다.

> **팁**
> - 같은 대화창에서 이어서 생성하면 캐릭터 얼굴이 잘 유지됩니다.
>   민서 이미지 3종(`minseo-full` → `minseo-talk` → `minseo-happy` → `avatar/minseo`)은
>   **한 대화창에서 순서대로** 만들어 주세요.
> - 결과물이 마음에 안 들면 "같은 캐릭터로, 표정만 ○○로 다시" 라고 이어서 요청하면 됩니다.
> - 글자가 들어가면 다시 생성해 주세요. 모든 텍스트는 앱이 DOM으로 그립니다.
