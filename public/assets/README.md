# 이미지 에셋

앱에서 사용하는 일러스트 에셋입니다. (SVG 미사용 — 모두 래스터 이미지)

## 기대하는 파일 이름

### scene/ — 배경 (가로형 1536×1024)
| 파일 | 용도 |
| --- | --- |
| `hallway.png`   | CASE 01 학교 복도 (메인 화면 · 단서 탐색) |
| `classroom.png` | 교실 |
| `stairs.png`    | 계단 |
| `garden.png`    | 학교 정원 |
| `rooftop.png`   | 옥상 |

### char/ — 인물 전신 (투명 배경, 세로형)
| 파일 | 용도 |
| --- | --- |
| `minseo-full.png`  | 민서 — 휴대폰 보는 전신 (복도 장면 전경) |
| `friends-full.png` | 친구 3명 그룹 — 대화 중 전신 (복도 장면 배경) |

### avatar/ — 원형 프로필 (정사각형)
| 파일 | 용도 |
| --- | --- |
| `minseo.png`     | 민서 프로필 (상담 대화 헤더) |
| `friend-boy.png` | 남학생 프로필 |
| `ai-helper.png`  | AI 도우미 로봇 (좌하단) |

### ui/
| 파일 | 용도 |
| --- | --- |
