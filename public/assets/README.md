# 이미지 에셋

앱에서 사용하는 일러스트 에셋입니다. 모두 래스터 이미지(PNG)입니다.

생성용 프롬프트는 [`PROMPTS.md`](./PROMPTS.md) 에 있습니다.
**파일 이름과 폴더 경로를 아래 표와 정확히 똑같이** 맞춰서 올려 주세요.
(대소문자·하이픈까지 동일해야 코드에서 자동으로 잡힙니다.)

## 업로드 후

이미지가 올라오면 컴포넌트를 인라인 SVG에서 이미지 기반으로 교체합니다.
현재는 파일이 없어 깨진 이미지가 뜨지 않도록 기존 SVG 일러스트
(`components/scene/HallwayScene.jsx`)를 그대로 사용 중입니다.
