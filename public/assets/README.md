# 이미지 에셋

앱에서 사용하는 일러스트 에셋입니다. 생성용 프롬프트는
[`PROMPTS.md`](./PROMPTS.md) 에 있습니다.

## 파일 형식

리포에는 **WebP** 로 커밋합니다. 생성 AI가 뱉은 PNG 원본이 장당 2MB가 넘어
수업 환경에서 너무 무겁기 때문입니다. (실측: 2228KB → 167KB, 육안 차이 없음)

코드는 확장자 없이 경로만 참조하고 `components/ui/AssetImage.jsx` 가
**`.webp` → `.png` → 플레이스홀더** 순으로 시도합니다.
그러니 **PNG를 그대로 올려도 동작합니다.** 다만 용량 때문에 PNG로 주시면
제가 WebP로 변환해 커밋하는 쪽을 권합니다.

**파일 이름과 폴더 경로를 아래 표와 정확히 똑같이** 맞춰 주세요.
(대소문자·하이픈까지 동일해야 자동으로 잡힙니다. 확장자만 자유입니다.)

### 받은 원본을 손본 내용

- 인물 컷아웃은 배경이 투명하지만 알파가 낮은 헤이즈가 캔버스 전체에
  퍼져 있어, 알파 40 미만을 잘라내고 인물 기준으로 크롭했습니다.
- `char/minseo-talk` 에는 소파가 반투명하게 함께 그려져 있습니다.
  임계값으로는 지워지지 않아, 어두운 배경 대신 03 상담실 배경 레이어에
  얹어 방 배경과 섞이도록 배치했습니다.
- `avatar/minseo` 는 상반신 원본에서 얼굴 중심 정사각형으로 잘랐습니다.
- `char/friends-full` 은 발까지 나온 버전으로 교체했습니다(2차 생성).
  이 그림은 투명 배경이 아니라 **갈색 그라디언트 배경**으로 와서, 테두리에서
  시작해 «이웃과 색이 거의 같으면 배경» 으로 번져 나가는 방식(허용차 8)으로
  걷어냈습니다. 단색 키잉으로는 그라디언트를 못 지우고, 허용차를 14까지
  올리면 오른쪽 남학생의 어두운 머리·가방까지 먹어 버립니다.
- 인물 컷아웃의 `aspectRatio` 는 **원본 파일 비율과 반드시 같아야** 합니다.
  다르면 `object-fit: contain` 이 좁은 쪽에 맞춰 축소해서, 발 위치는 그대로인데
  키만 줄어들고 원근이 어긋납니다.
- `ui/trophy` · `ui/badge-star` 는 정사각형으로 패딩한 뒤 줄였습니다.
  그냥 리사이즈하면 가로가 넓은 형태라 원형/사각 틀 안에서 한쪽으로 쏠립니다.
