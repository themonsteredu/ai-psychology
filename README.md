# 마음 SIGNAL LAB

AI 시대에 사람의 마음을 이해하는 직업을 체험하는 중학생용 진로교육 웹앱 프로토타입입니다.

## CASE 01
**친구 사이, 무슨 일이 생긴 걸까?**

학생은 마음 SIGNAL LAB의 신입 청소년상담사가 되어 가상 사례를 탐색합니다.

1. CASE 소개
2. 학교 복도 단서 탐색
3. 메신저형 상담 대화
4. 시그널 보드 분류
5. AI 상담 리포트 검토
6. 새로운 메시지와 사건 반전
7. 상담 전략 카드 조합
8. 상담사 직무역량 및 관련 진로 결과

## 교육 원칙
- 실제 심리진단을 하지 않습니다.
- 모든 사례는 가상 직업체험용입니다.
- 학생의 실제 우울·불안 등을 점수화하지 않습니다.
- 결과는 상담사 직무역량 학습 결과로만 보여줍니다.
- AI의 답변을 그대로 믿기보다 사실, 추론, 추가 확인 필요 정보를 구분하도록 설계합니다.

## 현재 구현 범위
- 순수 HTML/CSS/JavaScript 기반 1차 프로토타입
- 클릭형 단서 수집
- 선택형 상담 대화
- 드래그/클릭형 시그널 분류
- AI 리포트 판별 활동
- 반전 메시지
- 상담 전략 카드 조합
- 직업 연결 결과 화면

이 단계에서는 로그인, 데이터베이스, 실제 AI API 호출을 넣지 않았습니다.
